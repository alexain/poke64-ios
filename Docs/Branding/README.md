# Branding assets

This folder contains the current POKE64 branding assets used by the repository:

- `poke64-banner.png`: banner shown in the README.
- `poke64-icon-source.png`: square source artwork used to generate the iOS app icons.

The iOS application icon set is located in:

```text
POKE64/Assets.xcassets/AppIcon.appiconset/
```

POKE64 is designed to load a locally built `vice_x64sc_libretro` core.

- Source: https://github.com/libretro/vice-libretro
- VICE project: https://vice-emu.sourceforge.io/

The VICE source tree, compiled dylib, and firmware verification report are excluded from this repository. They are created locally.

The POKE64 build script removes detected exact firmware payloads from the unsigned core and refuses to finish when expected categories cannot be verified. ## Commodore firmware

POKE64 does not include BASIC, KERNAL, character, drive, or replacement firmware. The application provides an importer for user-supplied files. Copyright and licensing of imported firmware remain separate from the POKE64 frontend and VICE code.
